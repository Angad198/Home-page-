# 🚀 Premium Green Streak Homepage

A modern and premium homepage built using **HTML & CSS** with a futuristic green glassmorphism UI. This project was created to practice frontend design, improve UI skills, and strengthen GitHub portfolio projects.

## ✨ Features

- 🎨 Premium Green UI Design
- 🌟 Glassmorphism Effects
- 📱 Responsive Layout
- ⚡ Smooth Hover Animations
- 🖥️ Modern Navbar
- 📊 Stats Section
- 💎 Premium Cards Design
- 🌙 Dark Futuristic Theme

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Responsive Design
- Flexbox
- Modern UI Styling
